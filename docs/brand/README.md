# Starboard brand guidelines

Status: proposed design, November 2026.

Starboard is the canonical plain-text reference for product screens and flows across platforms. Its identity combines a navigation star (one guiding reference) with screen corners (layout boundaries). The name also evokes green starboard navigation lights.

![Starboard mark](starboard-mark.svg)

## Visual identity

Use the lowercase **starboard** wordmark in a clean semibold sans-serif, with slightly tight tracking. Pair it with the four-point star and corner-frame mark. The primary lockup uses mint artwork and white type on midnight; the light lockup uses midnight type and a midnight icon tile. Keep at least one quarter of the icon width clear around the mark. Use the simplified star alone at favicon sizes. Avoid gradients, shadows, literal ships, or stretching the mark.

| Token | Color | Usage |
|---|---|---|
| Midnight | #101E30 | Dark surfaces, primary text |
| Starboard green | #68DBC6 | Primary actions, mark, highlights |
| Ocean slate | #426479 | Secondary surfaces, borders |
| Sea mist | #F5F7F8 | Light backgrounds |
| Pale mint | #C1F5E8 | Optional star facet |
| Deep teal | #087F70 | Accent text on light surfaces |

Use midnight text on mint buttons; avoid mint text on white. Verify WCAG AA contrast before shipping. Suggested typography: Inter or system sans-serif; system monospace for terminal examples. These are proposed choices, not existing product requirements.
