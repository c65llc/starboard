# Contributing to Starboard

Thank you for your interest! Starboard is new and its file formats are still
stabilizing.

## Reporting Issues

Open a [GitHub Issue](https://github.com/c65llc/starboard/issues) with a clear
title, steps to reproduce, the `starboard version` output, your OS, and — where
possible — a minimal `starboard.yaml` / `screens.yaml` that shows the problem.

## Feature Requests

Open an issue describing the problem you're trying to solve, the platforms and
form factors involved, and what you'd expect Starboard to do.

## Pull Requests

We are not accepting pull requests yet, while the formats and core API settle.
Issues and feedback are the most valuable way to shape the project right now.
Once the first stable release ships, this section will describe how to
contribute code.
