desktop-notes

An invented note-taking app for macOS, Windows and the web: seven screens and four flows.

Everything on this page is Starboard’s own output for examples/desktop-notes: starboard generate drew the wireframes and wrote the screen catalog, and the diagrams are the project’s Mermaid sources, drawn. The wireframes are grey boxes by design: they show each screen’s regions and their order, not a visual design.

App map

Section titled “App map”

Every screen, grouped by area, with the links between them (from generated/app-map.md). The screen catalog below lists each screen’s links in words.

Flows

Section titled “Flows”

Compare and delete notes

compare-and-delete-notes · status: shipped · starts at library.main

Goal: read two notes side by side, then throw away the one that is no longer needed.

Steps

Section titled “Steps”
  1. Open the first note in @notes.window: select it in @library.main#notes and choose Open in new window from @library.main#more.
  2. Select the second note in @library.main#notes and read the two side by side.
  3. Choose Delete from @library.main#more.
  4. Tap @notes.delete#delete; the note moves to the trash.
    • @notes.delete#cancel closes the dialog and keeps the note.

The flow’s source

Export a note

export-a-note · status: shipped · starts at library.main · platforms: macos, windows

Goal: keep a copy of a note as a file another app can open.

Steps

Section titled “Steps”
  1. Select the note in @library.main#notes.
  2. Choose Export from @library.main#more.
  3. Choose a format in @notes.export#format and a place in @notes.export#location.
  4. Tap @notes.export#export.

Platform adaptations

Section titled “Platform adaptations”
  • web: @notes.export is proposed; the web app cannot export yet.

The flow’s source

Set up the library

set-up-the-library · status: shipped · starts at library.main

Goal: make a notebook for a new subject and set the editor up the way you like it.

Steps

Section titled “Steps”
  1. Choose New notebook from @library.main#app-menu.
  2. Name it in @notebooks.new#name and tap @notebooks.new#create; it is selected in @library.main#notebooks.
  3. Choose Preferences from @library.main#app-menu to open @settings.preferences.
  4. Pick a theme in @settings.preferences#theme and a font in @settings.preferences#font.

Platform adaptations

Section titled “Platform adaptations”
  • web: there is no preferences window; steps 3 and 4 do not apply.

The flow’s source

Write and share a note

write-and-share-a-note · status: shipped · starts at library.main

Goal: write a new note and let someone else read it.

Steps

Section titled “Steps”
  1. Pick a notebook in @library.main#notebooks, then tap @library.main#new-note.
  2. Type a title in @library.main#title and the text in @library.main#body.
    • The note saves as you type; there is no save button.
  3. Tap @library.main#share.
  4. Type who to share with in @sharing.share#people and choose @sharing.share#access.
  5. Tap @sharing.share#send; they appear in @sharing.share#shared-with the next time it opens.
